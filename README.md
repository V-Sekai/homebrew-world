# Homebrew for V-Sekai Projects

This repository is a Homebrew tap that provides formulae and casks for V-Sekai projects, making it easier to install and manage them on macOS and Linux.

## Installing V-Sekai Godot Editor

To install the V-Sekai Godot Editor using Homebrew, follow these steps:

1.  **Tap the repository:**

    ```bash
    brew tap V-Sekai/homebrew-world
    ```

2.  **Install the vsekai-godot package:**
    This single command will install the correct version for your operating system (macOS or Linux).
    ```bash
    brew install v-sekai-godot
    ```

## Official Project Documentation

For more details about the V-Sekai Godot Editor and its features, please refer to the official project repository:

- **V-Sekai Godot Project:** [https://github.com/V-Sekai/world-godot](https://github.com/V-Sekai/world-godot)

This tap includes both a macOS cask definition (for graphical application bundle installation) and a unified formula capable of installing on macOS and Linux.
